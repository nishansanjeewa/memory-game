# 🧠 Memory Game

A classic browser-based card matching game built with vanilla JavaScript. Test your memory by finding all matching pairs of cards as fast as possible!

[**🚀 Play the Live Demo**](https://nishansanjeewa.github.io/memory-game/)

## 🎮 How to Play

1.  Click on a card to flip it over.
2.  Click on a second card to try and find a match.
3.  If they match, they stay flipped.
4.  If they don't match, they flip back over.
5.  Find all pairs to win the game!

## ✨ Features

* **Responsive Design:** Playable on desktop, tablets, and mobile phones.
* **Move Counter:** Tracks how many moves it takes you to win.
* **Timer:** (Optional: remove if you don't have this) Races against the clock.
* **Restart Button:** Quickly reset the board to play again.

## 🛠️ Technologies Used

* **HTML5:** Semantic structure.
* **CSS3:** Flexbox/Grid for layout and animations for card flipping.
* **JavaScript (ES6):** Game logic, DOM manipulation, and state management.
